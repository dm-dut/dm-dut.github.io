# V6 changes

- Elsevier: no article-detail requests; PII-first incremental discovery.
- Elsevier: optional search-card date; publication month/year is display-only.
- IEEE: replaced long PublicationTitle search/RSS with the user's simple Early Access/TOC URLs.
- IEEE: no date retrieval and no article-detail requests.
- Added immutable fetched_date.
- Default sorting: fetched_date desc, journal asc, true online date desc, source_rank asc.
- New schema `6-id-first`; older database is reset automatically.
