Paper Monitor V6 ID-FIRST — 快速使用
====================================

第一次：
1. 把压缩包内容覆盖到 dm-dut.github.io 仓库根目录。
2. 运行 1_SETUP.bat。
3. 打开 paper_monitor_system\.env，填写 SPRINGER_API_KEY。
4. 运行 2_BROWSER_WARMUP.bat（首次处理 ScienceDirect/IEEE cookie/consent）。
5. 运行 3_TEST.bat。
6. 先运行 4_FETCH_LOCAL.bat 检查本地结果。
7. 确认代码已 commit 后，运行 5_UPDATE_AND_PUSH.bat。

以后每天：
- 手工：5_UPDATE_AND_PUSH.bat
- Windows 计划任务：update_papers_scheduled.bat

核心逻辑：
- Elsevier：ScienceDirect 搜索页 + PII。新 PII 就保留，不打开文章详情页。
  有 Available online 就显示；没有则显示搜索页中的发表年月。
- IEEE：你之前提供的简洁 Early Access/TOC 链接 + Document ID。新 ID 就保留，不查日期、不打开详情页。
- Springer：Meta API + onlineDate。
- 默认网页排序：获取日期↓ → 期刊名↑ → 真正 online 日期↓ → 页面顺序↑。
